# Work & Study To-Do List

A simple, responsive to-do list for planning work and study sessions. It runs entirely in your browser, so there is no server or installation required.

## Features

- Start with a set of suggested tasks organized into **Plan**, **Focus**, and **Wrap up**.
- Add your own tasks, mark tasks complete, or delete individual tasks.
- See your completion count, progress bar, and remaining task count update as you work.
- Remove all completed tasks with **Clear completed**.
- Save task changes in the browser using `localStorage`, so they remain available when you reopen the page in the same browser.
- Use the layout on desktop or mobile screens.

## Getting started

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add, complete, or remove tasks as needed.

No package manager, build step, or web server is required.

## Usage notes

- Your tasks are stored locally in the browser. They are not synced across devices or browsers.
- Clearing browser data or site storage may remove the saved list.
- If browser storage is unavailable or full, changes may not be saved; the app reports save errors in the page and browser console.
